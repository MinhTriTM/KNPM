# Suy nghĩ (Thinking)

CRITICAL INSTRUCTION 2: Các công cụ liên quan để thực thi: `write_file` (để ghi log). Không cần dùng tool đọc/tìm kiếm vì tôi đang sinh nội dung lý thuyết từ bộ nhớ để chat trực tiếp với user.

Tiếp tục mở rộng phần 3 của "Chuyên đề Tự luận phân tích kinh điển". Đây sẽ là các câu hỏi lấy điểm Giỏi (9-10) thường gặp trong đề thi, đi sâu vào kỹ thuật và framework:
- Câu 11: Scrum Framework (Chi tiết 3 roles, 3 artifacts, các events).
- Câu 12: Mối quan hệ Include và Extend trong Usecase.
- Câu 13: Độ phức tạp Cyclomatic (V(G)) và cách thiết kế Test case Path Coverage.
- Câu 14: Reverse Engineering (Dịch ngược) vs Forward Engineering.
- Câu 15: Phân tích 3 loại quan hệ lớp (Aggregation, Composition, Inheritance).
